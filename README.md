# Projekt 1 - Panel rezerwacji miejsc w kinie

Prosty projekt szkolny wykonany w React i Bootstrap.

## Uruchomienie

1. Instalacja bibliotek:
   npm install

2. Uruchomienie serwera:
   npm run dev

## Wykorzystane technologie

- React + JavaScript
- Bootstrap 5
- Bootstrap Icons
- React Router DOM

## Zrealizowane funkcjonalności

- Lista 6 filmów z tytułem, gatunkiem, czasem trwania, opisem, plakatem i seansami
- Filtrowanie filmów po gatunku
- Wyszukiwanie filmu po tytule
- Wybór konkretnego seansu
- Sala kinowa 6 rzędów po 8 miejsc (zielone - wolne, czerwone - zajęte, niebieskie - wybrane)
- Możliwość zaznaczania i odznaczania wolnych miejsc
- Licznik wybranych miejsc
- Wybór rodzaju biletów: normalny (25 zł) i ulgowy (18 zł) oraz automatyczne liczenie ceny
- Formularz z walidacją: imię, nazwisko, e-mail
- Podsumowanie rezerwacji po zatwierdzeniu
- Zadanie na 6: zapisywanie rezerwacji w localStorage, historia rezerwacji, możliwość anulowania, routing React Router, podstrona O kinie, podstrona Kontakt oraz sortowanie filmów
